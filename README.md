BudgetBuddy 💰
A minimalist personal finance tracking app for Android, designed to help college students and young professionals manage their money without the complexity of traditional budgeting tools.

Features
Quick Expense Tracking - Add expenses with simple category selection
Budget Management - Visual progress bars for spending categories
Bill Reminders - Track upcoming bills with due date alerts
Income Monitoring - Record multiple income sources
Spending Insights - Basic charts and spending analysis

Tech Stack
Frontend: Native Android (Java/Kotlin)
Backend: Firebase (Database & Auth)
Hosting: Google Cloud Platform
Development: Android Studio

Getting Started / Basics
Clone the repository
Open in Android Studio
Configure Firebase credentials
Build and run on Android device/emulator

Target Audience
College students, young professionals, and anyone seeking simplified financial management tools.
